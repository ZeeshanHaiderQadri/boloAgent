Bolo platform supports Deepgram, OpenAI, Google, Azure Speech, AssemblyAI, Speechmatics, Cartesia, Gladia, Soniox, Sarvam, Smallest AI, Hugging Face, ElevenLabs, and Bolo transcribers. You can take a look at the providers documentation of which language to select for your language requirements. 

<Warning>
Transcriber providers receive the data needed to transcribe speech, such as call audio, language settings, keyterms, and request metadata. Review the provider's data processing, retention, model training, and regional hosting policies before using sensitive data.
</Warning>

For locally deployed or self-hosted STT models, Bolo also supports Speaches, an OpenAI API-compatible server for streaming transcription. Whisper models served through Speaches list Urdu (`ur`) alongside Hindi (`hi`); the voice and transcriber presets on the model configuration page set the right language for you. The Speaches connection needs no API key or paid subscription; see [Free local speech](./voice#free-local-speech) for the server and model download commands.

If the Speaches connection uses an English-only distil model (any model whose ID ends in `.en`), choosing Urdu or Hindi on a call switches transcription to `Systran/faster-whisper-large-v3` for the session, so download that model once on the server.

Example: Deepgram has their language support documentation at https://developers.deepgram.com/docs/models-languages-overview#nova-3

## OpenAI language

OpenAI transcription (`gpt-4o-transcribe`) takes an ISO 639-1 language code. Every request names one, so set **Language** in the STT tab to what callers speak — `ur` for Urdu, `hi` for Hindi. At the default `en`, other languages are rendered as English words instead of being auto-detected. Picking a language on a Bolo Agent call sets this for the session.

## Deepgram Flux language hints

With the `flux-general-multi` model, **Language hints** biases transcription toward the languages you expect callers to speak. Pick several when callers switch between known languages, for example Hindi and English. Hints are combined with the **Language** setting, and leaving both on auto-detect lets Flux detect the language on its own.

Hints only help within the languages Flux multilingual supports. They do not add new ones. See [Deepgram's language prompting guide](https://developers.deepgram.com/docs/flux/language-prompting).

In **Bolo** mode, language hints are also available when you select auto-detect (`multi`) or a Flux-supported language. For bilingual English/Spanish calls, choose auto-detect and check **English** and **Spanish** under **Language hints**. These hints bias recognition toward both languages; they do not guarantee that other languages will be excluded.

Selecting a specific Flux-supported language combines that language with your hints. Hints are hidden and unused when you select a language that Bolo routes to its standard transcriber.
